# HLPlanet Keyboard API

Free JSON API for keyboard size data from [HLPlanet](https://www.hlplanet.com/): standard layouts from full-size to 60%, the measured case size of 30 keyboards, side-by-side comparisons, desk and mousepad fit, and which sizes have a given key. No API key.

- **Docs:** https://api.hlplanet.com/
- **OpenAPI:** https://api.hlplanet.com/openapi.json
- **For AI agents:** https://api.hlplanet.com/llms.txt (every docs page also has a `.md` version)

```bash
curl "https://api.hlplanet.com/v1/compare?items=tkl,75"
```

The numbers match the interactive [HLPlanet keyboard size comparison](https://www.hlplanet.com/keyboard-layout/). The same data is available as MCP tools in [hlplanet-mcp](https://github.com/hlplanet/hlplanet-mcp).

## Develop

A Cloudflare Worker with no runtime dependencies.

```bash
npm install
npm test          # every endpoint, error codes, docs, llms.txt and OpenAPI
npm run typecheck
npm run deploy    # needs `npx wrangler login` once
```

`src/data.ts` and `src/keyboards.ts` are shared with hlplanet-mcp and the EmDash plugin. Docs pages live in `src/docs.ts`; their examples are generated by the real handlers.
